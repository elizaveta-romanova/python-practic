# Мои учебные проекты на Python

Здесь собраны задачи, которые я решала в процессе обучения аналитике данных.

## Что умею

- Писать функции на Python
- Работать со списками и строками
- Фильтровать данные, считать суммы, средние, количество
- Находить максимумы и минимумы
- Считать гласные и согласные

## Примеры задач

- `sum_range` — сумма чисел от 1 до n
- `filter_even_range` — список чётных чисел
- `count_vowels` — количество гласных в слове
- `max_vowels` — слово с максимумом гласных
- `average_letters` — средняя длина слов в списке
